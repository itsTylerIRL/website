        §01 At a glance radgotchi @ 28e2288 · MIT

        AWAKE

        RadGotchi is a radbro that lives on your screen: a transparent, always-on-top window holding a 144×44 pixel-art face. It watches your system (CPU, memory, network, hung apps, whether you're at the keyboard) and reacts with one of 25 hand-drawn moods. Click it and it opens the SIGINT Terminal, a CRT-styled chat with whatever local language model you point it at — which can call tools, remember things about you and see what you attach.

        Engagement earns XP: levels, clearance ranks, milestones, daily contracts and an arcade where XP is the currency. It needs feeding and rest, finds other RadGotchis on your LAN, and since October 2026 runs headless as a phone-first web app you can install on an iPhone home screen.

        §02 Architecture Electron main + renderers · 21 main modules

        Standard Electron split: a main process that owns the windows, system access, persistence and the network, and renderers that draw the pet and the terminal. main.js (180 lines) only boots; src/main/bootstrap.js wires the modules together. In web mode headless.js runs the same main-process modules under plain Node, and src/web/web-bridge.js stands in for Electron IPC in the browser.

        §03 Pet & moods 25 sprites · 10 routines · 4 movement modes

        The face is one of 25 sprites, tinted to any colour through an SVG filter (default #ff3344; the choice syncs to every window, the web UI and mesh peers) with a breathing glow. Moods last a few seconds then settle back to awake; status text cycles in English or Chinese. Pick any sprite in the Sprite Roster panel, or play an idle routine below or in the Specimen viewer.

        Linux & Hyprland

        Drag to move, scroll to scale. On Linux the pet runs through XWayland so it can position itself; under Hyprland it reads the cursor position and the space reserved by bars from Hyprland's IPC socket, because XWayland can't see either. Recommended hyprland.conf rules make it float, pin, and drop borders, shadow and blur.

        §07 Arcade arcade-data.json

        XP is the currency. Wins, losses and profit are tracked per game and persisted in arcade-data.json with the inventory.

        ◉

        Coinflip 5–500 XP

        A win pays 1.8× (a 10% house edge on double-or-nothing).

        ♠

        Blackjack 10–500 XP

        Hit, stand, or double down on the first action; naturals checked on the deal, auto-stand at 21, pushes return the bet.

        ▦

        Shop §05

        Spend XP on consumables; items go to the inventory until used.

        §08 SIGINT terminal & LLM any OpenAI-compatible endpoint

        Click the pet to open the terminal: CRT scanlines, streaming replies rendered as markdown with copyable code blocks, file attachments with previews, an activity log, the XP bar, needs, Pomodoro, mesh panel and an audio equaliser. History persists between sessions.

        Backends

        Ollamalocalhost:11434/v1/chat/completions
        LM Studiolocalhost:1234/v1/chat/completions
        LocalAI / otherany OpenAI-compatible endpoint; several profiles can be saved
        chatstreaming, temperature 0.8, short replies (200 tokens)
        toolsup to 5 tool-call rounds per message; tool rounds run non-streaming at temperature 0.3 with 2,048 tokens
        memoryafter each reply the pet extracts facts about you and keeps up to 50 (pet-memory.json), injected into the system prompt; can be viewed, cleared or disabled
        vibe modecaptures desktop audio (WASAPI / ScreenCaptureKit / PipeWire loopback) and makes the pet dance to it, with a live equaliser

        §10 RAD MESH SIGINT-1.0 · UDP 47823

        Peer discovery and chat between RadGotchis on the same LAN over UDP broadcast. Peers show up in the terminal's network panel with node ID (e.g. RG-A3F2K9), operator name, rank, level, colour and signal strength; mesh messages persist in mesh-messages.json.

        §11 Headless web mode :7777 · no display needed

        npm run start:headless runs RadGotchi over SSH with no display: a Node-only server for a phone-first web UI (the pet in its chamber plus the full terminal), installable as an iPhone home-screen app with an offline screen.

        npm run start:headless                 # 127.0.0.1:7777
tailscale serve --bg 7777              # https://<machine>.<tailnet>.ts.net
npm run start:headless -- --host=::    # or: all interfaces, IPv4 + IPv6, plain HTTP
        listen127.0.0.1:7777 by default; Tailscale Serve recommended for HTTPS with a real certificate
        logina 24-byte random token (web-token, mode 600, stable across restarts); /?token=… sets an HttpOnly cookie, or send Authorization: Bearer; compared in constant time. Delete the file or set RADGOTCHI_WEB_TOKEN to rotate
        transporta minimal RFC 6455 WebSocket with no dependencies, 30 s keep-alive, plus an HTTP fallback (/api/invoke, /api/send, SSE /api/chat-stream)
        hardening16 MB body limit (413), CSP, Referrer-Policy: no-referrer; run_command and create_file are off unless RADGOTCHI_ALLOW_DANGEROUS_TOOLS=1
        at bootcontrib/radgotchi-web.service systemd user unit + loginctl enable-linger
        TRUST

        Keep web mode behind Tailscale or a trusted LAN — anyone with the token drives the pet and its tools.
