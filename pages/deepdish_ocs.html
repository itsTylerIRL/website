      What it is

      OCS (Optical Control System) turns a Gakken Worldeye — a small projector that paints an image onto the inside of a frosted sphere — into an eye that watches the room. A webcam finds people; the eye follows them, reacts with expressions, drifts through moods when nobody is around, and fires alerts for the hour, sirens and aircraft passing overhead.

      Everything goes through one HTTP API, so the same controls are available from the desktop GUI (tkinter), the web UI at :5001, the touch UI at /mobile, raw curl, and Home Assistant.

      §03 Render pipeline

      Each frame is painted with OpenCV/NumPy from the back of the eye forward. Every layer has a named style; a preset is just a choice for each layer plus colors and motion. Frames are cached for 33 ms while active (30 fps) and 120 ms when idle; low-memory mode uses 50 / 200 ms.

      §04 Behavior & mood

      The eye's mood is a Valence / Arousal / Dominance vector. It decays exponentially toward a baseline; stimuli (a face appearing, motion, idle time, manual expressions) nudge it, and the mood biases which behaviors fire and how strongly. The 30 most recent stimuli are kept as a feed for the web UI.

      axisrangebaselinedecay / sreads as
      valence−1 … +10.050.020sad / angry ↔ happy / content
      arousal0 … 10.300.040calm / sleepy ↔ excited / alert
      dominance0 … 10.500.015timid ↔ confident

      Expressions

      Expressions last 0.5–10 s at an intensity of 0–1, play their own sound and push the mood by (ΔV, ΔA, ΔD) × intensity, so manual triggers keep the eye's "feeling" consistent with its face.

      expressionΔVΔAΔD
      happy+0.20+0.100
      sad−0.20−0.10−0.05
      angry / mad−0.15+0.30+0.20
      surprised+0.05+0.30−0.05
      confused−0.02+0.10−0.10
      suspicious−0.05+0.05+0.10
      bored−0.05−0.200
      thinking0−0.05+0.05
      neutral000

      Behavior tree

      With reactive expressions on, each tick scores the behaviors whose conditions hold; each has a cooldown so the eye doesn't repeat itself.

      behaviorfires whendoescooldown
      WelcomeBacka face returns after >25 s away (or >40 s idle)surprised (or angry)30 s
      EnjoyingFacea face has been tracked for >4 shappy 3.5 s180 s
      ConfusedByMotionno face, average motion >0.35confused 3 s15 s

      IdleMoodno face, no movement for >20 sbored or sad 4 s25 s

      §05 Tracking

      Face tracking picks the best backend that actually works on the host and logs why each faster one failed — important for diagnosing CUDA driver / wheel mismatches and broken MediaPipe builds.

      orderbackendmodeldevice
      1YOLOyolov8n-face.pt, falls back to yolo11n.pt (person)CUDA
      2YOLOsame modelsCPU
      3MediaPipeface detectionCPU
      4OpenCVHaar frontalface_defaultCPU, last resort

      On top of detection: smoothed gaze toward the locked face, face-lock dynamics, idle wandering with dwells and sweeps, a smoothed motion average that feeds the behavior tree, and a surprised reaction (with cooldown) when a new face appears. /api/calibration tunes the gaze mapping; /api/tracking toggles it.

      §06 Alerts & takeovers

      alertendpointbehavior
      hourly chime/api/eye/hourly-chimeon the hour, a chime animation (5 s per cycle) with a jingle and a smooth gaze transition
      siren/api/eye/sirenfull-eye siren animation with sound; optional duration

      thinking/api/eye/thinkingthinking state while a chat / LLM reply is pending

      Only one takeover animation (siren, flyover, chime) runs at a time, and a flyover is refused while the siren is active.

      Flyover monitor

      src/services/flyover.py polls community ADS-B APIs (no key required) for aircraft within a radius of home. A new aircraft entering the zone below the altitude ceiling triggers the flyover animation — the aviation sibling of the hourly chime.

      sourcesadsb.lol, then airplanes.live (kept as an API-compatible fallback after provider policy changes)
      radius3.0 nm
      ceiling15,000 ft (ignores high-altitude cruisers)
      pollevery 15 s, on a background thread
      locationlat / lon, or a zip code geocoded via zippopotam.us; persisted to flyover_config.json

      §07 Audio & voice

      mixerpygame, 44.1 kHz stereo, 512-sample buffer, 16 channels with a reserved alert channel for ducking
      effects36 files: three variants each for the eight expressions, plus blink, chime, chime jingle, face detected / lost, lock, flyover, siren, startup, shutdown, reconnect
      variationper-play pitch jitter and live tone synthesis through pygame.sndarray (/api/sound/synth)
      recoveryan audio health monitor names its PipeWire / Pulse stream, notices when the default sink changes or the stream disappears, and re-initialises the mixer (/api/sound/reconnect)
      voiceChatterbox TTS cloned from a reference clip (assets/mech.wav); exaggeration and cfg_weight per request; load / unload on demand to free VRAM
      chat/api/chat proxies to an OpenAI-compatible /v1/chat/completions server on the local network (avoids CORS in the web UI)

      Eye window placement

      The eye is normally fullscreened on a secondary display — the Worldeye's projector. Window managers open new windows on whichever monitor has focus, so src/app/window_placement.py saves the placement when the window goes fullscreen and restores it at the next start (eye_window.json). Monitors are identified through Hyprland (hyprctl); other window managers fall back to the saved screen position.
