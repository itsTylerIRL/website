      §02 Architecture privileged container · host PID + network

      TOP is deployed as a privileged Docker container with full host namespace access: PID, network and hardware. The container runs a Gunicorn WSGI server with gevent async workers, enabling Server-Sent Events and parallel metric collection across all subsystems.

      §03 Backend & collectors nsenter -t 1 · ThreadPoolExecutor

      System metric collectors all in parallel

      Every collector reads the host via nsenter -t 1 (PID namespace) or /proc/1/root (mount namespace), and every metric is gathered in parallel with ThreadPoolExecutor.

      get_system_info()kernel, arch, distro, CPU model, core counts, total RAM: cached indefinitely
      get_cpu_info()per-core %, total %, frequency, load averages via psutil
      get_memory_info()total / used / available RAM + swap via psutil
      get_disk_info()3-strategy fallback: /proc/1/mounts → nsenter df → psutil; real filesystems only
      get_network_info()per-NIC I/O, interface details, top 80 active connections
      get_processes()top 50 processes by CPU%: PID, name, user, RSS / VMS, threads, FDs
      get_gpu_info()NVIDIA nvidia-smi: temps, utilization, VRAM, power, fan speed
      get_temperatures()psutil.sensors_temperatures(): current / high / critical thresholds
      get_docker_containers()all containers, live stats fetched in parallel per running container
      get_systemd_services()top 50 services via systemctl, D-Bus fallback

      mDNS IPv4 resolution cache

      A DNS layer for .local hostnames on the LAN, needed because mDNS can return IPv6 or resolve to the wrong interface on dual-homed machines.

      candidatesavahi-resolve, socket.getaddrinfo, configurable fallbacks
      ttl120 seconds
      invalidationautomatic on connectivity failure

      DEEPDISH intake portal

      Accepts text, URL or image submissions. URLs auto-fetch their <title> and meta description; images are stored as base64 data URIs. Every note is saved to DEEPDISH/intake/ in the Obsidian vault with YAML frontmatter.

      Cluster node monitoring Prometheus node_exporter · max_workers=6

      Polls node_exporter (port 9100) on six LAN nodes in parallel. Parsed from the Prometheus text format: CPU, memory, disk, network I/O, load averages and uptime.

      §13 Security posture trusted LAN only

      RISKS
      • the container runs privileged with host PID / network: required for full system visibility
      • HA token and Obsidian API key live in .env, not in version control
      • the Obsidian API uses self-signed HTTPS, so SSL verification is off
      • the frontend redacts non-local IPs (142.███.███.███)
      • chat history redacts personal names → OPERATOR / ASSET-2
      • Docker / systemd management is exposed without auth: trusted LAN only
      CLASSIFIED

      Additional security protocols and network segmentation details are classified under Directive ████-██ and cannot be disclosed in this document. Access requires SCI compartment authorization.
